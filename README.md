# RemindToDeleteMedia Privacy Policy

This repository contains the public privacy policy for RemindToDeleteMedia.

- Privacy policy: [PRIVACY_POLICY.md](PRIVACY_POLICY.md)
- Web version: https://sudarshanchaudhari.github.io/remindtodeletemedia-privacy-policy/
- Contact: sunny.sudarshan@gmail.com

## What not to lose from this policy

Three statements earn their place, because an app named *RemindToDeleteMedia* holding photo and video permissions invites the opposite assumption:

1. **The App never deletes media.** No deletion API is called anywhere, and no write or delete permission over media is requested.
2. **It reads folder metadata, not image content** — except for thumbnails drawn in the preview screen for a folder the user chose to preview.
3. **Nothing can leave the device.** No `INTERNET` permission in the finished app.

Any future edit must keep all three.

## Editing

`PRIVACY_POLICY.md` is the source of truth. `index.html` carries the same content for GitHub Pages and must be updated in the same commit — Pages serves `main` at the repository root with no build step, so a change to the Markdown alone does not reach the published page.

The copy in the [RemindToDeleteMedia app repository](https://github.com/SUDARSHANCHAUDHARI/RemindToDeleteMedia/blob/main/PRIVACY_POLICY.md) is kept identical to this one.

This README no longer duplicates the policy text. It used to, which left three copies of the same document drifting apart.
